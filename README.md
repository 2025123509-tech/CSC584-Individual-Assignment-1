# CSC584 Individual Assignment 1: Personal Profile Web Application

A simple profile application. It collects details in an HTML form, sends them to a Java Servlet using HTTP POST, and displays the submitted information on a JSP page.

## Technologies

- HTML5 and CSS
- Java Servlet API
- JavaServer Pages (JSP)
- NetBeans IDE 8.2
- GlassFish Server 4.1.1 (Java EE 7 Web)

## Project files

The complete NetBeans project, source code, and output screenshots are included in [CSC584PersonalProfile.zip](CSC584PersonalProfile.zip). Download and extract the ZIP file before opening the project in NetBeans.

## Run in NetBeans

1. Open the extracted `CSC584PersonalProfile` folder in NetBeans IDE 8.2.
2. Make sure GlassFish Server 4.1.1 is registered and running.
3. Right-click the project and choose **Run**.
4. Open the project URL shown by NetBeans (usually `http://localhost:8080/CSC584PersonalProfile/`).
5. Fill in the form and select **Create My Profile**.
